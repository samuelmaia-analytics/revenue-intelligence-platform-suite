# Tests

## Purpose
This directory contains the suite-level validation layer for platform behavior, executive artifacts, governance controls, and productization workflows.

## Coverage Areas
- smoke tests for Streamlit and API surfaces
- contract and showcase validation
- semantic metric and configuration regression
- deal room, proposal, publication, and approval workflows
- repository governance controls
- SSO and tenant-secret readiness behavior

## Why It Matters
The test suite is one of the clearest signals that this repository is production-minded. It validates not only code paths, but also the commercial and governance artifacts that make the platform reusable in client delivery.
