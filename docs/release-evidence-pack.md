# Release Evidence Pack

## Purpose
Package the executive proof required for a credible release, quarterly review, or client steering committee.

## Contents
- showcase summary
- solution profile
- quality scorecard
- executive insights
- adoption metrics
- monitoring summary
- executive review pack in markdown and JSON
- executive review pack in HTML
- client proposal pack
- client microsite
- manifest of included artifacts

## Commands

```bash
python scripts/build_executive_review_pack.py
RELEASE_TAG=v1.0.0 python scripts/build_release_evidence_pack.py
```

## Why This Matters
- gives a reusable proof pack for client and leadership reviews
- supports recurring service delivery with a standard release artifact
- turns technical release evidence into something commercially consumable
