# Proposal Pack

## Purpose
Generate a client-facing proposal asset from the same executive artifacts used in the showcase and review pack.

## Outputs
- `dist/client-proposal-pack/client_proposal.md`
- `dist/client-proposal-pack/client_proposal.html`
- `dist/client-proposal-pack/client_proposal.json`

## Command

```bash
python scripts/build_client_proposal_pack.py
```

## What It Uses
- solution profile and branding
- executive insights
- quality scorecard
- benchmark reference for the selected industry

## Commercial Value
- shortens proposal creation time
- creates a white-label starting point by industry
- keeps the sales narrative aligned with the platform runtime and governance artifacts
