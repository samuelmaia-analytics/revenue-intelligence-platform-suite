# Client Microsite

## Purpose
Generate a static client-facing microsite that combines proposal framing, executive branding, and a review-pack preview.

## Command

```bash
python scripts/build_client_microsite.py
```

## Output
- `dist/client-microsite/index.html`

## Sales Engineering Use
- share a branded static handoff after a discovery call
- package proposal and executive review narrative in one lightweight artifact
- reuse the same runtime-backed content for pre-sales and delivery handoff
