# Productization Roadmap

Delivery reference: [docs/diagrams/delivery-motion.md](./diagrams/delivery-motion.md)

## Quick Wins
- Rewrite the root README as a technical-commercial landing page.
- Publish commercial documentation for packaging, pricing logic, and implementation motion.
- Surface executive insight artifacts and data quality scorecards in the showcase.
- Clarify who buys the solution, what outcomes it drives, and how it is delivered recurrently.

## Executive Upgrades
- Add an explicit executive narrative layer to the flagship app.
- Expand recommended-action management with ownership, ETA, and status controls.
- Add client-ready storyboards and screenshots for demos by vertical.
- Introduce board-level summary exports and meeting-pack outputs.

## Platform Upgrades
- Consolidate client, environment, and solution-package configuration into a first-class config framework.
- Formalize bronze, silver, gold promotion with stronger lineage and artifact metadata.
- Add versioned business contracts for source, semantic metrics, and executive outputs.
- Expand health checks to freshness SLAs, anomaly detection, and regression gating.
- Standardize connector registration and compatibility for multi-client deployments.

## Productization Upgrades
- Add white-label theming and client-specific navigation presets.
- Introduce API-serving capability for KPIs, actions, and scorecards.
- Create delivery accelerators by vertical with connector templates and semantic mappings.
- Package recurring-service operating rituals, proof packs, and release evidence as standard deliverables.
