# Industry Demo Packs

## Purpose
Generate reusable commercial demo packs tailored to different buyer contexts and industries.

## Current Profiles
- `saas_b2b`
- `healthtech_growth`
- `retail_omnichannel`

## Commands

```bash
python scripts/build_industry_demo_packs.py
python scripts/build_synthetic_benchmark.py
```

## Outputs
- `dist/industry-demo-packs/<profile>/executive_review_pack.html`
- `dist/industry-demo-packs/<profile>/client_proposal.html`
- `dist/industry-demo-packs/<profile>/executive_review_pack.json`
- `dist/industry-demo-packs/<profile>/summary.json`
- `dist/benchmarks/industry_benchmark.csv`

## Commercial Use
- tailor proposal walkthroughs by industry
- shorten discovery cycles with pre-built narratives
- compare benchmark targets across client archetypes
