# Datasets

## Purpose
This directory is reserved for small, anonymized, development-safe samples that help with local experimentation, smoke tests, and documentation examples.

## Operating Rules
- keep only lightweight, non-sensitive samples
- never store client production data here
- prefer derived or synthetic examples over raw personal data
- align usage with [docs/privacy-and-lgpd-policy.md](../docs/privacy-and-lgpd-policy.md)

## Positioning
The platform is designed for enterprise analytics and recurring client delivery. That means this directory is intentionally not a landing zone for operational client exports. It exists to support reproducibility without compromising governance.
